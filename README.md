An interactive wearable experience designed for ArCH Square, Singapore.

## Overview
This project helps museum visitors explore traditional porcelain-firing craftsmanship through thermal, vibration, audio, and visual feedback.

## Hardware
- ESP32-WROOM-32
- 2 × Peltier modules
- 2 × vibration motors
- K-type thermocouple + MAX6675
- FQP30N06L MOSFET drivers
- 3D-printed wearable housing

## Software
- Arduino IDE / ESP32 firmware
- HTML, CSS and JavaScript
- ESP32 Wi-Fi Access Point
- LittleFS for hosting website files

## Interaction
- 30-second simulated firing process
- 38°C wearable temperature target
- Single vibration near 1200°C
- Double vibration near 1300°C
- 41°C software safety cut-off

## Project Status
Working prototype developed for CDE5312.
